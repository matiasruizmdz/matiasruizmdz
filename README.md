## Sobre mí

Soy **Matías Ruiz**, desarrollador de software de **Mendoza, Argentina**, con más de **4 años de experiencia** construyendo soluciones web escalables, seguras y orientadas al rendimiento.

Tengo una fuerte inclinación hacia el **backend**, trabajando principalmente con **Node.js, TypeScript, Python, FastAPI, Express, bases de datos SQL/NoSQL, microservicios, Docker y AWS**.

Me interesa crear software robusto, mantenible y bien documentado, aplicando buenas prácticas de arquitectura, testing, seguridad, performance y despliegue.

Actualmente me desempeño como **Ssr Backend Developer en SMS Sudamérica**, participando en soluciones backend, integraciones, automatizaciones y sistemas orientados a entornos productivos.
